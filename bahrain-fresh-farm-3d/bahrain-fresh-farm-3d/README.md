# Bahrain Fresh Farm — 3D website preview

React + Three.js + React Three Fiber interactive concept.

## Local setup

```bash
npm install
npm run dev
```

## Vercel

Import this repo at https://vercel.com/new, select Vite, build command `npm run build`, output directory `dist`. No environment variables needed.

## Notes

The initial 3D animals are stylized placeholders, not photorealistic 3D models. Photos are representative Unsplash images, **not** the real farm. Replace with properly licensed 3D GLB/GLTF animals and verified farm photos for a production launch.
